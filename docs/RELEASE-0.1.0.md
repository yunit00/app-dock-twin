# Dock Twin 0.1.0

Первая публичная предварительная версия второй Dock-панели для macOS.

## Скачать

- **Dock-Twin-0.1.0-arm64.dmg** — приложение, ссылка на «Программы», инструкция установки и MIT-лицензия.
- **Dock-Twin-0.1.0-arm64.zip** — то же приложение в ZIP, инструкция и лицензия.
- **SHA256SUMS.txt** — SHA-256 для проверки обоих архивов.

Выберите DMG или ZIP. Архивы Source code предназначены для разработчиков; для запуска они не нужны.

## Установка

Откройте DMG, перетащите Dock Twin в «Программы» и запустите его оттуда. Для ZIP распакуйте архив и перенесите приложение в «Программы».

**Только Apple Silicon (M1 и новее), macOS 14+.** Проверено вручную на macOS 26; другие версии и установка на другом Mac пока не проверены.

**Нет Developer ID и нотарификации Apple.** macOS может блокировать первый запуск. Если доверяете сборке, после попытки запуска используйте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», если кнопка доступна. [Инструкция Apple](https://support.apple.com/en-us/102445).

## Возможности

- Приложения, файлы и папки; индикаторы запущенных приложений без дублирования.
- Перенос из Finder и системного Dock, перестановка иконок по всей ширине панели со сдвигом соседей.
- Четыре стороны экрана, выбор монитора, масштаб, увеличение, отключение анимаций и автоскрытие.
- Режим «Только на рабочем столе», включённый по умолчанию: окна перекрывают панель.
- Сетка папок, контекстные меню и сохранение настроек.

Это ещё не полная замена системного Dock: нет списка окон, Genie, чужих badges, корзины, автозапуска и автоматических обновлений. Плавность последних изменений перетаскивания требует дальнейшей ручной оценки. Пройдены 20 автоматических проверок.
