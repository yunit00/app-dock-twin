# Dock Twin 0.1.1

В Twin отображаются только закреплённые объекты. Запуск других приложений больше не добавляет их на панель. У закреплённых приложений сохраняются точки-индикаторы запуска. Удалённое из Twin приложение не возвращается, даже если продолжает работать.

Убрана настройка автоматического показа запущенных приложений. Старое значение этой настройки игнорируется; закрепления и порядок сохраняются.

## Установка

Скачайте DMG или ZIP для Apple Silicon (M1 и новее). Завершите прежний Dock Twin через значок в строке меню и замените приложение в «Программах». Минимум macOS 14; ручная проверка проводилась на macOS 26. Intel не поддерживается этой сборкой.

Сборка предварительная, без Developer ID и нотарификации Apple. Если macOS блокирует запуск, следуйте [инструкции первого запуска](https://github.com/yunit00/app-dock-twin#первый-запуск-и-предупреждение-macos).

В релиз включены DMG, ZIP и SHA256SUMS.txt. Исходники и приложение распространяются по MIT.
