Dock Twin 0.1.0 — предварительная версия

Требования: Mac с Apple Silicon (M1 или новее), macOS 14+.
Проверялось на macOS 26. Intel в готовой сборке не поддерживается.

Перетащите Dock Twin.app в Applications / Программы.
Запускайте приложение из «Программ», затем извлеките DMG.
Дополнительные инструменты или исходники не нужны.

Сборка без Developer ID и нотарификации Apple. Если macOS блокирует запуск
и вы доверяете этой сборке, после попытки открытия перейдите в
Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»,
если эта кнопка доступна. Инструкция Apple:
https://support.apple.com/en-us/102445

Панель по умолчанию справа и перекрывается окнами приложений.
Шестерёнка открывает настройки. Выход — через значок в строке меню.
Перед обновлением завершите Dock Twin и замените приложение в «Программах».

Исходники, инструкция, обратная связь:
https://github.com/yunit00/app-dock-twin
