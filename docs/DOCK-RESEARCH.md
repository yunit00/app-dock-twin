# macOS Dock — карта поведения

Исходная платформа — macOS 26.6.2. Дата исследования — 7 ноября 2026.

Документ фиксирует функциональный охват и статус первой реализации. Визуальная идентичность и совпадение кривых анимации требуют дальнейшего сравнения на устройстве. Закрытая реализация Apple не изучалась.

## Интеграции операционной системы

Эти возможности требуют отдельного прототипирования. Для них нет реализации в 0.1.

- **Окна приложений и свёрнутые окна.** Проверить Accessibility API для списка окон, активации и сворачивания. Потребуется разрешение пользователя на управление доступностью.
- **Genie и Scale.** Системная анимация направлена в системный Dock. Перенаправление в стороннюю панель через публичный API пока не подтверждено.
- **Значки уведомлений, прогресс и запросы внимания.** NSDockTile предоставляет приложению его собственный элемент. Публичный способ читать и зеркалить все чужие элементы пока не подтверждён.
- **Меню, которые приложения добавляют в Dock.** Универсальный публичный API для получения меню других приложений пока не найден.
- **Handoff, недавние документы, Mission Control и App Exposé.** Требуют отдельной проверки доступных системных интерфейсов и ограничений.
- **Резервирование рабочего пространства.** Панель размещается внутри visibleFrame. Окна других приложений могут находиться под ней. Публичный эквивалент резервирования края системным Dock пока не подтверждён.
- **Полноэкранные приложения.** У панели включены canJoinAllSpaces и fullScreenAuxiliary. Фактическое отображение в разных fullscreen-сценариях ещё требует проверки.

## Последовательность доведения

1. Проверить ежедневное использование базовой панели, drag-and-drop, сохранение, мониторы и автоскрытие.
2. Довести геометрию, подписи, анимацию увеличения, раскрытие папок и клавиатуру по сравнению с системным Dock.
3. Добавить список окон через Accessibility, корзину, недавние приложения и автозапуск.
4. Отдельно оценить системные интеграции и зафиксировать достижимый уровень совместимости.
