# Dock Twin

Вторая нативная Dock-панель для macOS. Swift + AppKit, macOS 14+, без внешних зависимостей.

## Запуск

Нужны Command Line Tools с Swift 6 или Xcode 16+.

```sh
./scripts/build-app.sh
open "dist/Dock Twin.app"
```

Скрипт собирает `.app` и подписывает его локальной ad-hoc подписью. Для распространения потребуется Developer ID и notarization.

Для создания установочного образа с приложением и ссылкой на «Программы» выполните `./scripts/build-dmg.sh`. Результат появится в `dist/Dock Twin.dmg`.

Исходная иконка находится в `assets/DockTwin.png`. Сборка создаёт из неё набор размеров macOS и файл ICNS.

## Использование

- Панель при первом запуске расположена справа.
- Перетащите приложения, файлы или папки из Finder на панель.
- Перетащите иконку на другую, чтобы поставить её перед ней в той же секции.
- Нажмите на приложение или файл для открытия, на папку — для раскрытия сетки.
- Правый клик открывает действия объекта, включая удаление из панели.
- Шестерёнка в конце панели открывает настройки масштаба, анимаций и расположения.
- Перетаскивание между Dock Twin и системным Dock использует файловые ссылки. Приложения помещайте в секцию приложений системного Dock, файлы и папки — в секцию рядом с корзиной.
- Значок Dock Twin в строке меню открывает настройки, добавление объектов и выход.
- В настройках доступны четыре края экрана, монитор, масштаб, увеличение, переключатель анимаций и автоскрытие.
- При автоскрытии подведите курсор к выбранному краю монитора.
- Command-click показывает объект в Finder. Option-click скрывает запущенное приложение. Command-Option-click активирует приложение и скрывает остальные.

Настройки сохраняются в UserDefaults домена `com.yunit.docktwin`. Закреплённые объекты хранят файловые bookmarks для восстановления перемещённых объектов.

## Проверки

```sh
swift build
./scripts/test.sh
```

## Состояние

Версия 0.1 — работающая основа. Есть системная полупрозрачная подложка, увеличение, анимация нажатия, индикаторы приложений, раскрытие папок сеткой и сохранение настроек. Полная идентичность macOS Dock ещё не достигнута.

Список окон, Genie, зеркалирование чужих badges, Handoff, корзина, веер папок, недавние приложения и полная клавиатурная навигация остаются в работе. Режим верхнего края и выбор конкретного монитора добавлены для второго Dock.
