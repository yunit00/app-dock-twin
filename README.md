# Dock Twin

Вторая нативная Dock-панель для macOS. Swift + AppKit, macOS 14+, без внешних зависимостей.

## Скачать и установить

**[Скачать Dock Twin 0.1.0 для Apple Silicon (.dmg)](https://github.com/yunit00/app-dock-twin/releases/download/v0.1.0/Dock-Twin-0.1.0-arm64.dmg)** · [Все файлы релиза](https://github.com/yunit00/app-dock-twin/releases/tag/v0.1.0)

Это предварительная версия для Mac с чипом Apple M1 или новее. Минимальная версия системы — macOS 14; ручная проверка проводилась на macOS 26. На macOS 14–15 совместимость ещё требует проверки. Готовая сборка не поддерживает Intel.

1. Скачайте и откройте DMG.
2. Перетащите **Dock Twin.app** в **Applications / Программы**.
3. Запустите Dock Twin из «Программ». Панель появится справа; настройки доступны через шестерёнку и значок в строке меню.
4. Извлеките образ DMG. Для дальнейшей работы он не нужен.

Приложение самостоятельное: Xcode, Swift, Orca и исходники для запуска не нужны. ZIP в релизе содержит то же приложение как альтернативу DMG. `SHA256SUMS.txt` позволяет проверить целостность скачанных файлов.

### Первый запуск и предупреждение macOS

Сборка подписана локальной ad-hoc подписью, **без Developer ID и нотарификации Apple**. macOS может заблокировать запуск скачанного приложения.

Если вы доверяете этой сборке, после попытки запуска откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о Dock Twin и нажмите **«Всё равно открыть»**, если эта кнопка доступна. [Инструкция Apple](https://support.apple.com/en-us/102445). Если запуск по-прежнему не удаётся, создайте [issue](https://github.com/yunit00/app-dock-twin/issues) с версией macOS и текстом ошибки. Установка на другом Mac пока не проверена.

Для обновления завершите Dock Twin через значок в строке меню и замените приложение в «Программах». Настройки сохраняются. Автоматического обновления пока нет.

## Сборка из исходников

Нужны Swift 6 и macOS 26 SDK (Xcode 26 или соответствующие Command Line Tools): исходники используют NSGlassEffectView с проверкой доступности во время выполнения. Сборка создаётся для архитектуры текущего Mac.

```sh
git clone https://github.com/yunit00/app-dock-twin.git
cd app-dock-twin
```

```sh
./scripts/build-app.sh
open "dist/Dock Twin.app"
```

Скрипт собирает `.app` и подписывает его локальной ad-hoc подписью. Для распространения потребуется Developer ID и notarization.

Для создания установочного образа с приложением и ссылкой на «Программы» выполните `./scripts/build-dmg.sh`. Результат появится в `dist/Dock Twin.dmg`.

Исходная иконка находится в `assets/DockTwin.png`. Сборка создаёт из неё набор размеров macOS и файл ICNS.

## Использование

- Панель при первом запуске расположена справа. Режим «Только на рабочем столе» включён по умолчанию — окна приложений перекрывают панель. Галочка доступна в настройках расположения.
- Перетащите приложения, файлы или папки из Finder на панель.
- Перетаскивайте иконку вдоль своей секции — соседи раздвигаются и показывают место вставки. Отпускание сохраняет порядок, Escape отменяет перенос. Перемещение незакреплённого запущенного приложения закрепляет его. Анимация учитывает переключатель «Анимации» и системный Reduce Motion.
- Нажмите на приложение или файл для открытия, на папку — для раскрытия сетки.
- Правый клик открывает действия объекта, включая удаление из панели.
- Шестерёнка в конце панели открывает настройки масштаба, анимаций и расположения.
- Перенос приложений из системного Dock в Twin подтверждён пользователем на тестовом Mac с macOS 26. Также доступно добавление из Finder и перенос из Twin в системный Dock. Приложения помещайте в секцию приложений системного Dock, файлы и папки — в секцию рядом с корзиной.
- Значок Dock Twin в строке меню открывает настройки, добавление объектов и выход.
- В настройках доступны четыре края экрана, монитор, масштаб, увеличение, переключатель анимаций и автоскрытие.
- При автоскрытии подведите курсор к выбранному краю монитора.
- Command-click показывает объект в Finder. Option-click скрывает запущенное приложение. Command-Option-click активирует приложение и скрывает остальные.

Настройки сохраняются в UserDefaults домена `com.yunit.docktwin`. Закреплённые объекты хранят файловые bookmarks для восстановления перемещённых объектов.

## Состояние

Версия 0.1 — работающая основа. Есть системная полупрозрачная подложка, увеличение, анимация нажатия, индикаторы приложений, раскрытие папок сеткой и сохранение настроек. Полная идентичность macOS Dock ещё не достигнута.

Список окон, Genie, зеркалирование чужих badges, Handoff, корзина, веер папок, недавние приложения и полная клавиатурная навигация остаются в работе. Режим верхнего края и выбор конкретного монитора добавлены для второго Dock.

[Карта функций, источники и этапы](docs/DOCK-RESEARCH.md)

## Обратная связь и участие

Ошибки и предложения принимаются в [Issues](https://github.com/yunit00/app-dock-twin/issues), изменения — через Pull Request. Для ошибки укажите версию macOS, чип Mac, сторону панели и шаги воспроизведения. Перед отправкой изменений выполните `./scripts/test.sh`.
